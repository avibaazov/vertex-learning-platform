# Implementation prompt — Wire the home page "All Courses" grid to Sanity

## Goal
Replace the hardcoded 3-course array in `app/page.tsx` with the **seeded Sanity
courses**, fetched server-side through the existing read layer. No visual redesign —
the existing `CourseCard` and section layout stay; only the data source changes.

## Skills read
- None. UI is unchanged; this is read-wiring (AGENTS.md §5). Reuses the pattern
  established in `prompts/course-page.md` (approved + implemented).

## Code / data inspected
- `app/page.tsx` — `Home` is a sync server component. `AllCourses()` maps a local
  `courses: HomeCourse[]` constant (Next.js for Production / Docker Essentials /
  TypeScript Deep Dive) onto `<CourseCard>`. Local `DockerMark` SVG + `HomeCourse`
  type + `ReactNode` import exist only to serve that array.
- `components/ui/card.tsx` — `CourseCard({ title, description, glyph, glyphClassName,
  level, duration, modules })`; renders a `<Card>` (div) with a 48px glyph tile and a
  meta row of `chart`/`clock`/`file` items. No `href` prop, no `className` pass-through.
- `sanity/queries/courses.ts` — `COURSES_QUERY` already returns, per course:
  `_id, title, slug, summary, level, price, popular, studentCount, coverImage{…},
  instructor{…}, category{…}, moduleCount, lessonCount`, ordered `popular desc, title asc`.
  It does **not** return a total runtime. `courseCardFragment` is shared with
  `COURSE_BY_SLUG_QUERY`.
- `sanity.types.ts` — generated; `COURSES_QUERY_RESULT` is exported. Regenerated by
  `npm run studio:typegen` (config in `studio/sanity.cli.ts`: extracts `schema.json`,
  scans `../{app,components,lib,sanity}/**/*`, writes `../sanity.types.ts`).
- `lib/format.ts` — `formatRuntime(seconds)`, `titleCase(s)`, `secondsFrom(v)` (added in
  the course-page task).
- `sanity/lib/fetch.ts` — `sanityFetch<TResult>({ query, params?, revalidate?, tags? })`,
  `server-only`; pass the generated `*_QUERY_RESULT` type explicitly.
- Seed: 10 published courses, every one has `level` (`beginner`/`intermediate`/
  `advanced`, lowercase) and `moduleCount` 4. Lesson `duration` is an integer of
  seconds. Course total runtime is not stored.

## Decisions & assumptions
- **Add total runtime to the query**: extend `courseCardFragment` in
  `sanity/queries/courses.ts` with
  `"durationSeconds": math::sum(modules[].lessons[]->duration)` (a number, or `null`
  when a course has no lessons). This also adds the field to `COURSE_BY_SLUG_QUERY` —
  harmless/unused there; the course page keeps its current per-module summing.
- **Regenerate types**: run `npm run studio:typegen` so `COURSES_QUERY_RESULT` /
  `COURSE_BY_SLUG_QUERY_RESULT` gain `durationSeconds: number | null`. `sanity.types.ts`
  is generated output, not hand-edited.
- **`app/page.tsx`**: make `Home` `async`; fetch
  `sanityFetch<COURSES_QUERY_RESULT>({ query: COURSES_QUERY })`; pass the array to
  `AllCourses({ courses })`. Delete `DockerMark`, the `HomeCourse` type, the `courses`
  constant, and the now-unused `ReactNode` import.
- **Card mapping** (no `CourseCard` API change):
  - `glyph={course.title.charAt(0)}`, default `glyphClassName` (dark tile). The seeded
    courses have no brand marks and the 48px tile is not a cover-photo slot, so a
    first-letter tile is used for every card (consistent with the course page's cover
    fallback). Cropped picsum covers at 48px would look worse.
  - `description={course.summary ?? ""}`
  - `level={titleCase(course.level) ?? ""}`
  - `duration={formatRuntime(course.durationSeconds ?? 0) ?? ""}`
  - `modules={`${course.moduleCount ?? 0} modules`}`
  - `key={course._id}`
- **Make cards navigable**: wrap each `<CourseCard>` in
  `<Link href={`/courses/${course.slug}`} className="group block h-full">` (the card
  itself is unchanged; `h-full` keeps the equal-height grid).
- **Show all fetched courses** (not just 3). The grid is already
  `sm:grid-cols-2 lg:grid-cols-3` and wraps to multiple rows; there is no separate
  catalog route for a "top 3 + view all" split to point at. "View all courses" stays a
  `#` placeholder (unchanged, out of scope).
- Empty result → render the section heading with no grid (defensive; seed has 10).
- `revalidate` left at the `sanityFetch` default (60s).

- `sanity.types.ts` — regenerated via `npm run studio:typegen` (no manual edit).

## Requirements
- The "All Courses" grid renders one card per seeded course, from Sanity, with real
  title, summary, title-cased level, derived total runtime, and module count.
- Each card links to `/courses/<slug>`.
- No change to `CourseCard`, the section's heading/spacing, hero, waves, or footer strip.
- No hardcoded course data remains in `app/page.tsx`.

## Security considerations
- Fetch runs in the `Home` server component via the `server-only` client; the read
  token never reaches the browser.
- No user input, no writes, no `dangerouslySetInnerHTML`. Card data is plain course text.

## Acceptance criteria
- `/` shows 10 course cards (Next.js App Router in Depth, React Performance Engineering,
  … Practical Web Security), popular first.
- A card's meta row shows e.g. `Intermediate · 1h 59m · 4 modules` for
  "Next.js App Router in Depth".
- Clicking a card navigates to that course's detail page.
- `npx tsc --noEmit`, `npm run lint`, `npm run build` all pass; `sanity.types.ts` shows
  `durationSeconds` on `COURSES_QUERY_RESULT`.
